# tf-idf-chatbot
This is a chatbot made in C++ and runs in vs code terminal or any terminal. It uses tf-idf method to answer the user using cosine similarity with 'facts', the training data that can be easily changed in the code as it is just a bunch of strings.
I have also also connected grok api which takes over if the data in the code is not enough for answering.
Sign in to Grok and generate key and put that in your terminal by typing setx API_KEY "paste_your_key_here".
You can add different models and model names as you wish by changing it in the code.
The code will automatically edit your terminal settings to include special characters and emojis once you compile it.
